# Getting Started

This pipeline extracts a structured memory from transcript `.txt` files using CrewAI + Ollama. It preserves the artist's voice, contradictions, and uncertainty — see `docs/philosophy.md` for what that means in practice.

## Add Transcripts

Default input directory:

- `~/Documents/art-talks`

Each transcript should be a plain text file:

- `~/Documents/art-talks/<artwork-name>.txt`

`<artwork-name>` becomes the output folder name.

## Run

```bash
make
```

By default, outputs are written under `~/Documents/art-talks/<artwork-name>/`.

## Outputs

Per transcript, the pipeline creates:

- `~/Documents/art-talks/<artwork-name>/memory.json` — the primary artifact: threads, contradictions, tangents, open questions, and anchor quotes.
- `~/Documents/art-talks/<artwork-name>/memory.md` — a human-readable mirror of `memory.json`.

The following are legacy, opt-in derivations generated by default for now (see `docs/configuration.md`):

- `~/Documents/art-talks/<artwork-name>/tags.txt`
- `~/Documents/art-talks/<artwork-name>/facebook.txt`, `instagram.txt`, `deviantart.txt`, `pinterest.txt`
